## Собственный проект

Тема проекта: Каталог игр

Главный класс: Game

Почему этот объект нужен программе:
Класс Game позволяет хранить информацию о видеоиграх в одном месте, чтобы программа могла вести учет коллекции.

Какие данные хранит объект:
- Название (Title)
- Жанр (Genre)
- Год выхода (Year)
- Рейтинг (Rating)
- Статус прохождения (Complete)

Какие значения задаются через конструктор:
Название, жанр, год выхода и рейтинг передаются пользователем при создании игры.

Какие значения можно задавать автоматически:
Статус прохождения (Complete) автоматически задается как false (игра еще не пройдена)

## Дополнительное задание
Какое значение я решила задавать автоматически и почему?
Я решила автоматически задавать поле Complete (Пройдена ли игра) значением false. Логично, что когда мы только добавляем игру в каталог, мы еще в нее не играли
